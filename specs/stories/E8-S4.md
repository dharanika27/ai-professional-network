# E8-S4 — AI feature screens (Resume Review, Profile Optimization)

**Layer:** UI
**Group:** G
**Depends on:** E6-S4, E8-S1

## Description

Screens that present the AI Resume Review (with streaming display) and AI Profile
Optimization results, rendering structured, explainable output with grounding citations and
graceful AI error/loading states.

## Acceptance Criteria

1. The Resume Review screen triggers `POST /api/ai/resume-review` and progressively renders streamed review content as it arrives.
2. The review is displayed as structured sections (strengths, weaknesses, ATS issues, suggestions) with visible grounding citations, not a raw text blob.
3. The Profile Optimization screen triggers `POST /api/ai/profile-optimization` and renders section-specific suggestions with citations.
4. AI errors (rate limit 429, provider failure 5xx) render an accessible, actionable message and offer a retry, never a blank screen or stack trace.
5. Both screens show a clear loading/in-progress state while the AI request is pending and render correctly in light and dark themes.
