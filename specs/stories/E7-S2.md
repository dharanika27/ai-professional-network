# E7-S2 — AI Job Matching service (vector top-10 → LLM re-rank)

**Layer:** Service
**Group:** D
**Depends on:** E4-S2, E6-S1, E7-S1

## Description

Two-stage matching: embed the user's resume, retrieve the top-10 candidate jobs via
pgvector, then call Claude to re-rank them and produce a fit score with explicit fit and gap
explanations per job. Outputs are schema-validated.

## Acceptance Criteria

1. `match_jobs(user_id)` embeds the user's structured resume and retrieves the top-10 candidate jobs by vector similarity before any LLM call.
2. Claude re-ranks the 10 candidates and returns, per job, a numeric fit score (0–100), a fit explanation, and an explicit list of skill/experience gaps; the output is schema-validated.
3. The final result is ordered by descending fit score and persisted as JobMatch records.
4. With a small/weak seed set producing low-similarity candidates, the service still returns ranked results with honest low scores rather than failing.
5. An LLM failure after the single retry returns a safe error and persists no invalid match set.
6. The matching requires a parsed resume and returns an actionable message when none exists.
