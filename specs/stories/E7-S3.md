# E7-S3 — Job matching and job details API endpoints

**Layer:** API
**Group:** E
**Depends on:** E7-S2

## Description

Expose AI job matching and job details over authenticated HTTP, with per-user rate limiting
on the AI matching endpoint and graceful failure handling.

## Acceptance Criteria

1. `POST /api/jobs/match` returns 200 with a ranked list of matched jobs, each including fit score, fit explanation, and gaps, for an authenticated user with a parsed resume.
2. `GET /api/jobs/{id}` returns 200 with full job details or 404 if the job does not exist.
3. Calling match with no parsed resume returns a 409/422 with an actionable message rather than a 500.
4. Exceeding the per-user AI rate limit on the match endpoint returns 429 without invoking the LLM.
5. Both endpoints require authentication and return 401 without a valid token.
