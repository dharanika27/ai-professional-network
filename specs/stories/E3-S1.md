# E3-S1 — Profile repository and completion calculation

**Layer:** Repository
**Group:** B
**Depends on:** E1-S1, E1-S3

## Description

Persist the professional profile and compute its completion percentage. Stores headline,
summary, skills, education, experience, certifications, and projects, one profile per user.

## Acceptance Criteria

1. `get_profile_by_user_id(user_id)` returns the user's Profile or None, and a new user has exactly one profile created on first access or registration.
2. `update_profile(user_id, data)` persists changes to headline, summary, skills, education, experience, certifications, and projects atomically.
3. Completion percentage is recomputed on every update as a deterministic function of populated sections and returned as an integer 0–100.
4. A fully populated profile yields a completion percentage of 100 and an empty profile yields 0.
5. Updating one user's profile never mutates another user's profile (isolation verified by test).
