# E3-S2 — Profile service (view, edit, completion)

**Layer:** Service
**Group:** C
**Depends on:** E3-S1

## Description

Business logic for viewing and editing the professional profile, including validation of
profile fields and exposure of the completion percentage and recommended-next-action
signals used by the dashboard.

## Acceptance Criteria

1. `get_profile(user_id)` returns the profile DTO including the current completion percentage.
2. `update_profile(user_id, data)` validates field constraints (e.g., headline length, skills as a non-empty deduplicated list) and rejects invalid input with a typed validation error.
3. Skills are normalized on save (trimmed, deduplicated, case-preserved) so duplicates differing only by whitespace collapse to one entry.
4. The service computes a list of incomplete profile sections to drive dashboard "recommended next actions".
5. A user can only read and edit their own profile; a mismatched user id is rejected with an authorization error.
