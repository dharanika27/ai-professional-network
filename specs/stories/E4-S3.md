# E4-S3 — Resume upload/delete API endpoints

**Layer:** API
**Group:** E
**Depends on:** E4-S2

## Description

Authenticated endpoints for uploading a resume (multipart), retrieving its structured
content, and deleting a resume with its associated AI analyses.

## Acceptance Criteria

1. `POST /api/resume` with a valid PDF/DOCX under 5 MB returns 201 with a resume id and the structured resume content.
2. Uploading a file over 5 MB or of a disallowed type returns 422/415 with a clear message and stores nothing.
3. `GET /api/resume` returns 200 with the authenticated user's current resume metadata and structured content, or 404 if none exists.
4. `DELETE /api/resume/{id}` returns 204 and removes the file, metadata, and associated ResumeReview/JobMatch records; deleting another user's resume returns 403/404.
5. The upload disclosure that resume content is processed by an external LLM provider is surfaced in the API contract/response.
