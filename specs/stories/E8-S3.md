# E8-S3 — Profile and resume screens (View, Edit, Upload)

**Layer:** UI
**Group:** G
**Depends on:** E3-S3, E4-S3, E8-S1

## Description

Screens for viewing and editing the professional profile and for uploading a resume. Shows
profile completion, surfaces the external-LLM processing disclosure on upload, and provides
loading states for the parse operation.

## Acceptance Criteria

1. Profile View renders the authenticated user's profile from `GET /api/profile`, including a visible completion percentage indicator.
2. Profile Edit saves changes via `PUT /api/profile` and reflects updated values and completion percentage on success without a full reload.
3. Resume Upload accepts PDF/DOCX, rejects oversize/invalid files client-side with a clear message, and uploads via `POST /api/resume` with a visible loading state during parsing.
4. The external-LLM processing disclosure is displayed to the user before/at resume upload.
5. After a successful upload, the structured resume content (skills, education, experience) is displayed to the user.
