# E8-S1 — Design system, theming (light/dark), and responsive shell

**Layer:** UI
**Group:** F
**Depends on:** E2-S3

## Description

Establish the AI-first SaaS design system (NOT a LinkedIn clone): tokens, card-based
components, typography, soft rounded corners, subtle gradients, AI accents, light + dark
theming with OS default and manual toggle, and a responsive application shell. Built to WCAG
2.1 AA from the start.

## Acceptance Criteria

1. A design-token system defines colors, spacing, radii, and typography, and powers both light and dark themes from a single source.
2. Theme defaults to the OS preference and a manual toggle persists the user's choice across reloads.
3. Core components (button, card, input, nav shell) render correctly at mobile, tablet, and desktop breakpoints without layout breakage.
4. Interactive elements have visible focus indicators, sufficient color contrast (WCAG 2.1 AA), and are fully keyboard navigable.
5. `tsc` and `eslint` pass over the UI package with zero errors.
