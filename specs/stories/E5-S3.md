# E5-S3 — RAG retrieval service (retrieve-then-generate)

**Layer:** Service
**Group:** C
**Depends on:** E5-S2

## Description

The retrieval half of the RAG pipeline: given a query (e.g., resume text or profile
content), embed it, retrieve the most relevant KnowledgeChunks from pgvector, and assemble
a grounded context block with citations for the generation step used by the AI features.

## Acceptance Criteria

1. `retrieve(query_text, k)` embeds the query and returns the top-k KnowledgeChunks ordered by similarity score.
2. Retrieved chunks are assembled into a context block that includes each chunk's source attribution for citation.
3. Retrieval returns an empty-but-valid result (not an error) when the KB has no sufficiently similar chunks, allowing graceful downstream handling.
4. The number of retrieved chunks (k) is configurable and defaults to a bounded value to control prompt size.
5. The service exposes only the assembled context and sources, with no LLM call inside it (clean separation of retrieve from generate).
