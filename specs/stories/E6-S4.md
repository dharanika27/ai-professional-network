# E6-S4 — AI feature API endpoints (review, optimization) with rate limiting

**Layer:** API
**Group:** E
**Depends on:** E6-S2, E6-S3

## Description

Expose the Resume Review and Profile Optimization features over authenticated HTTP, with
per-user rate limiting on AI endpoints, streaming support for review, and graceful AI error
handling.

## Acceptance Criteria

1. `POST /api/ai/resume-review` returns 200 with the structured review (supporting a streaming response) for an authenticated user with an uploaded resume; 404 when no resume exists.
2. `POST /api/ai/profile-optimization` returns 200 with the structured optimization for the authenticated user's profile.
3. Exceeding the configured per-user AI rate limit returns 429 with a retry indication and does not invoke the LLM.
4. An upstream AI provider failure or timeout returns a 503/504 with a safe, actionable message and no internal detail.
5. Both endpoints require authentication and return 401 without a valid token.
