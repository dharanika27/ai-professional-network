# E7-S1 — Job repository, seed dataset, and embedding index

**Layer:** Repository
**Group:** B
**Depends on:** E1-S1, E1-S3, E5-S1

## Description

Persist seeded job postings (~500–1000 realistic records), embed each job description, and
index embeddings in pgvector for top-k retrieval. Architected so the seed source can later
be swapped for a real jobs API.

## Acceptance Criteria

1. A seed routine loads between 500 and 1000 realistic job postings (title, company, description, location, skills) into the Job table.
2. Each seeded job stores a 384-dimension embedding of its description produced by the EmbeddingProvider.
3. `retrieve_top_jobs(query_embedding, k=10)` returns the 10 nearest jobs by vector similarity, ordered by score.
4. `get_job_by_id(job_id)` returns the full job record or None.
5. The job source is abstracted behind a loader interface so a real jobs API can replace the seed without changing retrieval code.
