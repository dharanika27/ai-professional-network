# E3-S3 — Profile API endpoints

**Layer:** API
**Group:** E
**Depends on:** E3-S2

## Description

Expose profile view and edit over authenticated HTTP endpoints, returning the profile DTO
and completion metadata.

## Acceptance Criteria

1. `GET /api/profile` returns 200 with the authenticated user's profile DTO including completion_percentage; an unauthenticated request returns 401.
2. `PUT /api/profile` with a valid payload returns 200 and the updated profile reflecting the changes.
3. `PUT /api/profile` with an invalid payload (e.g., headline exceeding max length) returns 422 with field-level detail.
4. No response from these endpoints exposes another user's data or any internal persistence field.
5. The non-AI profile endpoints respond with p95 latency under 300 ms in a local benchmark.
