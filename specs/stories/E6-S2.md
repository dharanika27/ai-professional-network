# E6-S2 — AI Resume Review service (RAG-grounded, streaming, cached)

**Layer:** Service
**Group:** D
**Depends on:** E4-S2, E5-S3, E6-S1

## Description

Generate a structured, explainable resume critique grounded in retrieved KB material (ATS,
resume best practices). Streams output for responsiveness on long reviews and caches the
result by resume file hash so an unchanged resume returns a cached review.

## Acceptance Criteria

1. `review_resume(resume_id)` retrieves relevant KB context, calls Claude, and returns a schema-validated structured critique with sections (e.g., strengths, weaknesses, ATS issues, actionable suggestions).
2. Each critique item references the grounding source so the review is explainable, not generic.
3. A review for an unchanged resume (same file hash) is served from cache without a new LLM call, and a changed resume produces a fresh review.
4. The review supports streaming delivery of the generated content.
5. An LLM failure after the single retry returns a safe, actionable error and persists no partial/invalid review.
6. The persisted ResumeReview contains no raw resume text beyond what the critique requires, and logging excludes PII.
