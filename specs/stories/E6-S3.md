# E6-S3 — AI Profile Optimization service (RAG-grounded)

**Layer:** Service
**Group:** D
**Depends on:** E3-S2, E5-S3, E6-S1

## Description

Produce RAG-grounded, explainable guidance to improve the user's professional profile
(headline, summary, skills, section completeness), retrieving relevant KB material and
returning schema-validated structured suggestions.

## Acceptance Criteria

1. `optimize_profile(user_id)` reads the current profile, retrieves relevant KB context, calls Claude, and returns a schema-validated ProfileOptimization with concrete suggestions.
2. Suggestions are section-specific (e.g., rewritten headline, improved summary, missing-skill recommendations) and each references its grounding source.
3. The service requires a minimally populated profile and returns an actionable message when there is insufficient profile content to optimize.
4. An LLM failure after the single retry returns a safe error and persists no invalid optimization.
5. The optimization result is persisted and re-fetchable for display without re-invoking the LLM.
