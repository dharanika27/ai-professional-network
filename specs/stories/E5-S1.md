# E5-S1 — EmbeddingProvider abstraction with local bge-small model

**Layer:** Service
**Group:** A
**Depends on:** —

## Description

Provide a local embedding capability behind an `EmbeddingProvider` interface using
BAAI/bge-small-en-v1.5 via sentence-transformers, bundled in-container. The abstraction
allows a later swap to a hosted provider without touching callers. Used for resumes, job
descriptions, and KB chunks.

## Acceptance Criteria

1. An `EmbeddingProvider` interface defines `embed_text(str) -> vector` and `embed_batch(list[str]) -> list[vector]`.
2. The local implementation loads bge-small-en-v1.5 and produces 384-dimension float vectors.
3. The same input text yields a deterministic, identical embedding across repeated calls.
4. The model loads once and is reused (lazy singleton), so cold-start latency is incurred at most once per process.
5. Swapping the provider requires changing only configuration/wiring, not any calling service (verified by interface-only imports in callers).
